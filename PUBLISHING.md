A criação e a publicação foram autorizadas explicitamente por Bianca. O trabalho ficou restrito a este novo repositório; nenhum outro repositório foi alterado.

## Como os arquivos foram publicados

Os documentos Markdown, JSON e registros de interface foram publicados pelo editor web do GitHub. O upload direto de arquivos apresentou erro, mesmo após habilitada a permissão da extensão.

As 11 capturas reais foram convertidas de JPEG para PNG, sem alterar seus pixels, e enviadas como anexos pelo editor. Os relatórios apontam para esses anexos do GitHub. A pasta evidence/screenshots contém o índice visual das imagens, em vez de arquivos JPEG binários versionados.

O ZIP entregue à estudante preserva a estrutura original, os JPEGs e seu manifesto SHA256SUMS.txt. Os links de imagens e as notas de publicação deste repositório foram adaptados depois da criação daquele ZIP. O manifesto do pacote não descreve a versão adaptada do GitHub.

## Manutenção

Para uma nova execução, registrar data, ambiente, dados e resultados próprios. Preservar EX-001 como histórico. Não substituir um resultado por outro sem registrar que houve nova execução.

A assistência de IA está declarada no README. A reprodução independente pela estudante continua como próxima etapa de aprendizado.
